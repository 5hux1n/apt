# Doleo

Sileo 的 DEB 下载与本地仓库工具。将插件安装包保存在本地，按需选择版本下载、备份和重新安装。

- **仅下载不安装**：选择软件源中可用的版本，支持连同依赖下载。
- **本地仓库**：集中管理 DEB，查看版本与下载来源，支持导出及交给 Sileo 安装。
- **自动备份**：Rootless 版已停用升级前及安装时自动备份。
- **已购插件下载**：使用 Sileo 当前商店账户验证购买状态，获取授权后下载入仓。
- **来源与校验**：醒目标记其他源版本；索引提供 SHA256 时校验下载文件。
- **仓库管理**：设置版本保留数量，标记当前源中已不可用的版本。

## 使用方式

安装后重新打开 Sileo。软件包页顶部的 **Doleo** 可打开仓库；插件详情页安装按钮旁的图标提供下载与仓库入口。Rootless 版已停用两项自动备份。

下载已购插件前，请先在 Sileo 登录对应软件源账户，并打开该插件详情页。

## 从 Rootless 1.0.0 更新

如果已经出现 APT 钩子错误，请先用 Filza 打开 `/var/jb/etc/apt/apt.conf.d/`，将 `99doleo` 改名为 `99doleo.disabled`，再更新。1.0.1 会清理旧钩子配置，保留仓库文件和设置。
