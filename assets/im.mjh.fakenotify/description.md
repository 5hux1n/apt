一款模拟通知插件，允许配置多个通知任务，原生通知方案，支持通知栏、锁屏页面显示。

## 功能

- 配置多个通知任务，每个方案最多 20 条通知。
- 选择通知来源 App，自定义标题、副标题和正文。
- 每条通知独立设置发送日期和时、分、秒。
- 点击预览立即触发已保存方案，不改变原定时任务。
- 支持原生通知栏、锁屏页面显示，以及通知记录清空。

## 安装

支持 iOS 15–16：Rootless 使用 arm64 包，RootHide 使用 arm64e 包。

- [Rootless · 1.0.0](https://apt.mjh.im/pkg/FakeNotify_1.0.0_arm64.deb)
- [RootHide · 1.0.0](https://apt.mjh.im/pkg/FakeNotify_1.0.0_arm64e.deb)
