UU 远程键盘、鼠标与画面增强插件，快捷切屏功能已统一合并。

## 功能

- 常用组合快捷键：Shift+Enter、全选、撤销、剪切、复制、粘贴，自动使用 ⌘ 或 Ctrl。
- 圆盘鼠标滚轮，转动速度控制滚动速度。
- 工具栏快捷切换显示器，并高亮当前显示器。
- 记忆各显示器的缩放与位置，切回前台时恢复视角。

## 设置与升级

安装后彻底退出并重开 UU，在“我的 → 设置 → uu 远控增强”开启总开关，再选择需要的功能。首次使用全部关闭，关闭总开关保留子设置。旧切屏插件按包管理器提示替换，之后只需更新 uu 远控增强。

已安装测试包的用户，请在包管理器中手动选择正式版 1.0.2 覆盖安装。

## 兼容

iOS 15.0 及以上，UU 4.42.0（193）与 4.43.0（195）；Rootless / RootHide。
